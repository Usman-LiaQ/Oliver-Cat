# 🐾 Oliver Cat — DevWorkspace

> A sleek, distraction-free developer dashboard designed for fast note-taking, project logs, and quick system monitoring.

🌐 **Live Demo:** [amazing-travesseiro-bf0ffa.netlify.app](https://amazing-travesseiro-bf0ffa.netlify.app/)

---

## ⚡ Highlights

- **🐾 Oliver Cat Aesthetic:** Minimalist GitHub/Linear dark UI (`#0d1117`) designed for high focus.
- **⚡ Zero Lag Preloader:** Ultra-fast startup sequence with instant fade-out.
- **📝 Live Dev Logs:** Filterable developer notes, project updates, and learning logs.
- **💡 Daily Focus:** Interactive task checklist & live ping monitor.
- **💾 Local First:** Auto-saves your data instantly via `LocalStorage`.

`HTML5` • `CSS3 (Variables & Grid)` • `Vanilla JavaScript` • `Netlify`
